# Автоматизация

Автотесты для [PomidorQA](https://aiqa.su/pomidorqa) — сервиса коротких
звонков для QA и IT-специалистов. Участник регистрируется, указывает навыки
и свободные слоты, другие находят его в каталоге и бронируют встречу.

Здесь находятся тесты и вспомогательный код автоматизации на TypeScript +
Playwright. Зависимости и конфигурационные файлы расположены в корне
репозитория, поэтому команды `npm` запускаются из корневой директории.

## Планируемая структура

- `tests/unit/` — unit-тесты.
- `tests/api/` — API-тесты.
- `tests/e2e/` — E2E-тесты.
- `pages/` — Page Object-модели.
- `fixtures/` — переиспользуемые Playwright-фикстуры.
- `test-data/` — тестовые данные.
- `utils/` — вспомогательные функции.

## Подготовка окружения

```bash
npm ci
npx playwright install chromium
```

Проверка конфигурации:

```bash
npm run check
```
