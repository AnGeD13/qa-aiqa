# Автоматизация

Здесь будет находиться изолированный проект автотестов на TypeScript + Playwright.

## Планируемая структура

- `tests/ui/` — UI-тесты.
- `tests/api/` — API-тесты.
- `pages/` — Page Object-модели.
- `fixtures/` — переиспользуемые Playwright-фикстуры.
- `test-data/` — тестовые данные.
- `utils/` — вспомогательные функции.

Playwright, зависимости и конфигурация будут добавлены отдельным шагом после выбора тестируемого продукта.
