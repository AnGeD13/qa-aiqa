# Баг-репорты

Здесь будут храниться описания обнаруженных дефектов. Скриншоты и другие небольшие подтверждающие материалы следует помещать в каталог `attachments/`.

Рекомендуемые поля: ID, заголовок, окружение, предусловия, шаги, фактический и ожидаемый результат, серьёзность, приоритет и вложения.
