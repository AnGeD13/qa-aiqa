# Ручное тестирование

Артефакты ручного тестирования [Пиццаеда](https://aiqa.su/base/shop) — учебного интернет-магазина доставки пиццы для практики QA.

Проверяются каталог, поиск и фильтрация, корзина, промокод `QA60`, расчёт скидки и доставки, оформление заказа и контракт API `/api/course/v1/shop/*`. Вне области: авторизация, оплата, админ-панель и смена статуса заказа после создания.


## Что тестируется

- Каталог четырёх категорий (пицца, напитки, десерты, соусы) и карточка товара, включая недоступный «Чизкейк».
- Поиск по названию, описанию и бейджам. При активном поиске результаты показываются по всем категориям; фильтр одной категории работает только при пустой строке поиска.
- Корзина: количество от 1 до 20, удаление позиции при нуле, сумма товаров, скидка, доставка и итог.
- Промокод `QA60`: скидка 10% от суммы товаров до доставки, округление вниз до целых рублей. Бесплатная доставка от 1500 ₽, иначе 199 ₽.
- Оформление заказа (имя, телефон, адрес) и popup с номером, суммой и статусом `created`. Пустая корзина отклоняется.
- API товаров, корзины и заказов. Сессии изолируются заголовком `X-Course-Session`.
