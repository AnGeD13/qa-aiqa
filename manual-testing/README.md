# Ручное тестирование

В этом разделе будут храниться тестовые артефакты, подготовленные для выбранного продукта.

## Структура

- [`checklists/`](checklists/) — чек-листы функций и пользовательских сценариев.
- [`test-cases/`](test-cases/) — подробные тест-кейсы с шагами и ожидаемыми результатами.
- [`bug-reports/`](bug-reports/) — баг-репорты и подтверждающие материалы.
- [`test-reports/`](test-reports/) — отчёты о выполненном тестировании.

Материалы будут добавляться после выбора тестируемого продукта. Каждый документ должен содержать цель, область проверки, окружение и дату актуализации.
